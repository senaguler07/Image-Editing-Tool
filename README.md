# Image-Editing-Tool
It's a tool to edit images.

You can use the following keys on your keyboard while the application is running to edit the image:

* **`w`**: Restores the image to its original color.
* **`e`**: Converts the image to grayscale.
* **`r` / `t**`: Rotates the image 90 degrees clockwise (`r`) or counter-clockwise (`t`).
* **`y` / `d**`: Flips the image horizontally (`y`) or vertically (`d`).
* **`n`**: Inverts the colors of the image (`bitwise_not`).
* **`+` / `-**`: Increases (`+`) or decreases (`-`) the brightness and contrast.
* **`b`**: Applies a Gaussian blur filter (`GaussianBlur`).
* **`1` / `2**`: Shrinks (`1`) or enlarges (`2`) the image.
* **`s`**: Saves the currently edited image as `assets/kaydedilen.jpg`.
* **`q`**: Quits and closes the program.
